# 小鲸鱼捏捏

一只可以用手指捏的软体小鲸鱼：**按住会压扁，松手弹回来**，看它头顶的喷水孔一直冒水花。

手机浏览器直接打开就能玩，**单文件、零依赖、无需安装**。

## 在线玩

https://msqbhdz.github.io/whale-squish/

手机上打开手感最好（触摸拖动的反馈比鼠标自然）。

## 玩法

| 操作 | 效果 |
| --- | --- |
| 按住不放 / 往下拖 | 压扁：横向铺开、纵向压缩，身上还会皱起来 |
| 往上拽 | 轻微拉长 |
| 左右拖 | 顺着手指方向侧向压扁 |
| 松手 | 弹簧回弹，带一点过冲的抖动 |
| 右上角「复位」 | 立刻恢复原状 |

不用碰它也有东西看：头顶的喷水孔一直喷着水花，水珠围着帽子轻轻起伏。

## 一点实现说明

- 整只鲸鱼是内联 SVG，**轮廓是照着参考图程序化提取的**（不是目测手画），
  所以体形、眼睛、腮红的位置比例都对得上。
- 形变不是播放写死的动画：每帧的缩放值由**弹簧积分**算出来
  （`a = -k·x - c·v`），目标值来自手指位置。
  所以回弹和过冲是"物理"出来的。
- 水花和喷水孔**共用同一个坐标系**（都在形变组里），
  所以捏的时候水柱根部始终咬在洞口上，不会分家。

## 自定义

用编辑器打开 `index.html`，脚本开头几个变量就能换手感：

| 变量 | 作用 | 默认 |
| --- | --- | --- |
| `MAX_STRETCH` | 横向最多铺开多少 | 0.40 |
| `MAX_FLATTEN` | 纵向最多压扁多少 | 0.42 |
| `FULL_PRESS_PX` | 拖多少像素算"捏满"（越小越灵敏） | 130 |
| `STIFF` / `DAMP` | 弹簧硬度 / 阻尼（阻尼调小则抖得更久） | 200 / 16 |
